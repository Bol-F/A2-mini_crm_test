# A2 Mini CRM

Небольшое тестовое CRM-приложение для создания и просмотра карточек лидов.
Данные сохраняются локально, а этап сделки можно менять прямо в карточке.

## Технологии

- Python 3.12+
- FastAPI и Uvicorn
- SQLite через встроенный модуль `sqlite3`
- Pydantic
- Jinja2
- HTML, CSS и JavaScript без frontend-фреймворка
- pytest
- uv для Python, зависимостей, виртуального окружения и запуска команд

## Структура проекта

```text
app/
├── main.py              # FastAPI-приложение и маршруты
├── database.py          # инициализация SQLite и SQL-запросы
├── schemas.py           # Pydantic-схемы и допустимые значения
├── static/
│   ├── app.js           # загрузка, сохранение и изменение лидов
│   └── styles.css       # оформление и адаптивная вёрстка
└── templates/
    └── index.html       # русскоязычный интерфейс
tests/                   # автоматические тесты
.github/workflows/
└── tests.yml            # GitHub Actions
pyproject.toml           # зависимости и настройки проекта
uv.lock                  # зафиксированные версии зависимостей
```

## Локальный запуск

Установите [uv](https://docs.astral.sh/uv/), клонируйте репозиторий и выполните:

```shell
uv sync --locked
uv run uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000>.

Для запуска тестов:

```shell
uv run pytest
```

Другие менеджеры Python-зависимостей проекту не требуются.

## Хранение данных

При старте приложение автоматически создаёт файл `crm.sqlite3` и таблицу
`leads`, если их ещё нет. Команда `CREATE TABLE IF NOT EXISTS` не удаляет
существующие записи, поэтому лиды остаются после обновления страницы и
перезапуска сервера.

Локальные файлы SQLite исключены из Git. Тесты используют отдельные временные
базы и не изменяют базу разработки.

## API

| Метод | Путь | Назначение | Успешный статус |
|---|---|---|---|
| `GET` | `/` | Открыть интерфейс | `200` |
| `GET` | `/api/health` | Проверить доступность API | `200` |
| `GET` | `/api/leads` | Получить лиды, новые первыми | `200` |
| `POST` | `/api/leads` | Создать лид | `201` |
| `PATCH` | `/api/leads/{lead_id}/stage` | Изменить этап сделки | `200` |

FastAPI также предоставляет интерактивное описание API по адресу
<http://127.0.0.1:8000/docs>.

## Как устроен интерфейс

HTML-форма и области сообщений находятся в
`app/templates/index.html`. Стили, включая мобильную раскладку, находятся в
`app/static/styles.css`.

Логика кнопки «Сохранить» находится в `app/static/app.js`: она проверяет
обязательные поля, отправляет JSON в API, обрабатывает ошибки и безопасно
создаёт карточку через DOM-методы и `textContent`.

Тот же файл загружает сохранённые лиды при открытии страницы. Идентификаторы
уже показанных лидов отслеживаются, чтобы карточка не появилась дважды.

В каждой карточке есть список «Изменить этап». После выбора JavaScript
отправляет `PATCH`-запрос, временно блокирует список и обновляет карточку без
перезагрузки. При ошибке прежнее значение восстанавливается.

SQL-запросы и управление соединениями сосредоточены в `app/database.py`.
Маршруты в `app/main.py` только принимают запросы, вызывают функции хранения и
возвращают ответы.

## Ручная демонстрация

1. Запустите сервер и откройте главную страницу.
2. Нажмите «Сохранить» с пустой формой и проверьте русское сообщение об ошибке.
3. Заполните все поля и сохраните лид.
4. Убедитесь, что карточка появилась первой в списке и содержит введённые данные.
5. Обновите страницу: карточка должна остаться.
6. Остановите и снова запустите Uvicorn: карточка должна загрузиться из SQLite.
7. Измените этап сделки в карточке и убедитесь, что значение обновилось без
   перезагрузки.
8. Запустите `uv run pytest`.

## Использование нейросети

Нейросеть использовалась как помощник при первоначальном создании структуры
проекта, FastAPI-маршрутов, SQL-функций, интерфейса, JavaScript-логики,
автоматических тестов, документации и CI-конфигурации. Это не означает, что
каждая строка была написана вручную.

После генерации вручную просматривались структура проекта, схемы данных,
параметризованные SQL-запросы, HTTP-статусы, обработка ошибок, безопасный вывод
пользовательских данных и состав зависимостей. Все автоматические тесты
запускались локально.

В браузере вручную проверялись создание лида, обязательные поля, защита от
повторной отправки, отображение карточек, обновление страницы, перезапуск
сервера, изменение этапа и восстановление прежнего этапа при ошибке.

Во время этих проверок были исправлены отсутствующий favicon, который давал
ошибку `404`, читаемость русских сообщений, блокировка повторной отправки,
состояния загрузки и пустого списка, защита от повторного отображения карточки
и восстановление этапа после неудачного запроса.

## Известные ограничения

- Нет аутентификации и разграничения доступа.
- Нет удаления лидов и редактирования полей, кроме этапа сделки.
- Телефон проверяется только на непустое значение, без проверки формата.
- SQLite подходит для локального тестового проекта, но не рассчитан на большую
  распределённую нагрузку.
- Интерфейс и API используют один процесс FastAPI и локальный файл базы данных.
